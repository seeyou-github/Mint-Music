# 歌曲付费状态标签（access）

> 目标：搜索结果、歌单详情、专辑详情、作者主页、排行榜详情里的歌曲列表，在**歌手名左侧**
> 显示「VIP / 数字专辑 / 付费 / 下架 / 无版权」标签，不按音质区分。

## 一、插件契约

数据源插件在 `songOf()` 返回的歌曲对象里加一个字符串字段：

```js
{
  id, songmid, name, singer, albumName, duration, artwork, source,
  access: 'vip'        // '' 或不写 = 免费
}
```

| 值 | 含义 | 标签 |
| --- | --- | --- |
| `''` / 不写 | 免费 | 不显示 |
| `vip` | 会员歌曲（非会员只能试听） | VIP |
| `album` | 数字专辑（需购买整张） | 数字专辑 |
| `paid` | 单曲付费 | 付费 |
| `offline` | 已下架 | 下架 |
| `nocopyright` | 无版权 / 未上架 | 无版权 |

认不出的值一律当免费（`SongAccess.fromRaw`），避免插件写错字导致整片误标。

## 二、App 侧链路

```
插件歌曲对象 access
  → MusicSourceManager._musicInfoToSong → Song.access (SongAccess 枚举)
  → SongListItem._buildAccessTag  ← 歌手名左侧
```

- 只在 `SongListItem` 里渲染，所以搜索 / 歌单 / 专辑 / 作者 / 榜单 / 下载页共用一套。
- **不参与任何过滤**，纯展示。
- 随 `Song.toJson` / `toPersistJson` 持久化，收藏歌单里的标签不会丢。

### 与 `vipExclusive` 的区别（别混用）

| | `vipExclusive` | `access` |
| --- | --- | --- |
| 来源 | B 站充电专属 / 大会员专享 | QQ / 网易 / 酷我 / 酷狗的付费与版权状态 |
| 形态 | 布尔 | 枚举字符串 |
| 是否参与过滤 | 是（「隐藏B站会员专属歌曲」开关，**只对 B 站生效**） | 否 |
| 标签位置 | 右侧（时长左边） | 歌手名左侧 |

「隐藏B站会员专属歌曲」现在靠 `Song.isBilibiliSource` 限定平台，
别的平台的会员歌不会被这个开关吃掉。

## 三、四平台映射（2026-11 实测）

| 平台 | 场景 | 字段 | 规则 |
| --- | --- | --- | --- |
| QQ | 搜索 / 榜单 | `pay.payplay`、`pay.payalbumprice`、`size128/size320/sizeflac` | `payplay=1`→vip；`payalbumprice>0`→album；所有 size 都 0→nocopyright |
| QQ | 歌单 | `pay.pay_play`、`pay.price_album`、`file.size_*` | 同上（字段名带下划线） |
| 网易 | 搜索 / 歌单 / 榜单 | `fee`、`st`、`noCopyrightRcmd` | `fee=1`→vip；`fee=4`→album；`st<0`→offline；有 `noCopyrightRcmd`→nocopyright |
| 酷我 | 搜索 / 歌单 / 榜单 | `payInfo.feeType.{vip,song,album}`、`online` | `feeType.vip="1"`→vip；`song="1"`→paid；`album="0"`→album；`online="0"`→offline |
| 酷狗 | 搜索 / 榜单 / 歌单 | `Privilege`/`privilege`、`PayType`/`pay_type` | `pay_type=2`→album；`privilege=10/8`→vip；`pay_type` 其它非 0 值→vip |

## 四、踩过的坑

1. **QQ `price_track` / `paytrackprice` 恒为 200**（每首歌都有），拿它判会员会把整个列表标成付费。
   只认 `payplay` / `pay_play`。
2. **酷我 `copyright` 不是「有没有版权」**：实测榜单里正常可播的歌全是 `copyright="0"`，
   拿它判无版权会把整个榜单标成无版权。下架只看 `online="0"`。
3. **网易 `fee=8` 是「免费听低音质」**，不是会员；标成 VIP 会把大量免费歌误标。
4. **酷狗是按音质给权限的**（`A320Privilege`/`SQPrivilege` 可能一个 0 一个 10），
   按需求只报一个总体结论，不细分音质。
5. **QQ 无版权判定要保守**：只有所有 size 字段都存在且全为 0 才判 `nocopyright`；
   接口没给 size 字段时按「有文件」处理。
6. `privilege=8` 在酷狗既可能是「付费可试听」也可能只是「高音质要会员」，
   结合 `pay_type` 一起看（`pay_type=0` 才是真免费）。

## 五、实测样例

```
QQ 搜索「隔岸」   ：隔岸(女版)/姚六一/黄龄 → 免费 ；鸾音社版 → vip
QQ 榜单(热歌榜)   ：天龙八部之宿敌、我好像在哪见过你 → vip
网易 搜索「周杰伦」 ：屋顶 fee=8 → 免费 ；想你就写信 fee=1 → vip
酷我 榜单         ：小城、照亮(Live版) → vip ；歌单里「快乐老家(Live)」→ 下架
酷狗 搜索「生日快乐」：祝你生日快乐 Price=1990/pay_type=2 → 数字专辑
```
